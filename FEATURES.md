# Complete Feature Inventory and Implementation Status

This is a **source-based inventory of visible UI features and their connected application behavior**. “Implemented” means relevant code is present; it does not mean every interaction passed a browser test. The only freshly run test suite in this audit was the backend Q&A unit suite (9/9 passed). No full browser E2E audit was run.

## Status meanings

- **Verified by automated test:** exercised by a test run in this audit.
- **Implemented — not end-to-end verified:** code and integration paths exist, but browser-level behavior was not confirmed.
- **Partially implemented / demo data:** the interface exists but relies on seeded/sample data, a fallback, or incomplete integration.
- **Placeholder / not a real feature:** visible control or sample content is not backed by the real-world capability it might suggest.
- **Not found:** no implementation was identified in the supplied source.

## D. Demo/placeholder behaviors that must be stated accurately

1. **Audio player:** controls exist, but the same bundled sample WAV is used as a fallback and seeded meetings share the sample path. It is not evidence of meeting-specific audio playback.
2. **Chapters:** the tab renders stored chapter/topic rows and can request a seek to their timestamps, but chapter generation and alignment against real meeting audio are not implemented/verified. Treat the chapter data as demo placeholders.
3. **Transcript timestamps:** pasted text receives estimated timing; the application does not derive real timestamps from audio.
4. **Summaries/action items:** seeded data is supported; do not claim every summary or action item is generated by AI.
5. **AI Q&A:** backend tests cover expected behaviors and all 9 passed in the audit. The OpenAI-backed path was not separately tested; fallback answers can be deterministic/rule-based. Gemini settings exist but no Gemini implementation was confirmed.
6. **Export PDF:** PDF export uses the browser's print dialog/print styling rather than a backend PDF-generation engine.
7. **Auth and collaboration:** static/default identity; no actual user authentication, team permissions, or multi-user collaboration.
8. **Deployment:** no verified deployed URL or deployment pipeline was found in the supplied archive.

## F. Known technical debt

- Frontend API client uses `NEXT_PUBLIC_API_BASE_URL`, while `next.config.js` rewrites use `NEXT_PUBLIC_API_URL`.
- Database and static audio paths are relative to process working directory.
- Seed script drops/recreates ORM-managed tables; avoid on any database containing data to preserve.
- `.next-build/` and Python bytecode caches were included in the supplied archive as generated artifacts.
- SQLite `conversations` and `ai_messages` tables are not represented by the inspected ORM models.
- Action-item request bodies use generic dictionaries in routes instead of dedicated Pydantic input schemas.
- No real authentication or multi-tenant authorization.
- `datetime.utcnow()` deprecation warnings and a SQLite resource warning were observed during the Q&A test run; tests passed despite warnings.
